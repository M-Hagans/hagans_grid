Reflection: I’m still really new to all this CSS stuff, so figuring out CSS Grid felt like a little adventure. The hardest part was definitely minmax. I had no clue what it did at first, so I had to look it up just to understand why everyone keeps using it. Then I learned that when you mix minmax with things like auto-fit, the browser basically decides how many columns to make on its own. I didn’t have to tell it anything—it just did the math for me. I also had to learn how to actually get the pictures onto the page by following the instructions step by step. Once I finally got them showing up, I had to look up how to make one photo stretch across two columns using grid-column: span 2. I realized this is the same kind of layout you see on Pinterest, where everything moves around when you resize the window.
